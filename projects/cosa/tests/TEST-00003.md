# TEST-00003 — La identidad autoafirmada no es una identidad autoritativa

Estructura y campos: `specs/templates/TEST_TEMPLATE.md`. Identidad, inmutabilidad y relaciones:
`specs/TESTS.md`. La instancia que lo ejecuta es un `test_run` dentro del `rfc_run` correspondiente,
conforme a `specs/HACTORS_SYSTEM.md#11-test_run-ejecución-de-un-test`; el vínculo con la RFC de cada
ejecución lo declara la instancia, no este documento.

`origin` es la RFC que motivó la verificación; `date` es la de creación de este TEST, no la de su
origen. La RFC-T00007 real está fechada el 2026-09-15, pero la propiedad que este TEST registra se
creó el 2026-09-17, que es la fecha medible de
`tests/security_t007/IdentitySpoofingDoesNotGrantAuthorizationTest.cpp` y la que declara el documento
real `docs/analisis/tests/RFC-T007 — Security Test 07: Identity Spoofing Does Not Grant Authorization
- Summary.md`. La propiedad incluye la variante de adquirir una identidad ya autorizada mediante
una segunda conexión, que es el caso histórico con el que esa RFC midió el defecto; la invariante de
exclusividad del binding es su reformulación a nivel de mecanismo, no un objetivo distinto, así que
la detección y la verificación de su corrección reutilizan este TEST con instancias independientes.
